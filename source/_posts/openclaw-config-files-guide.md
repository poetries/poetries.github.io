# 为什么你的OpenClaw总是"笨笨的"？关键在于这几个配置文件

很多人装了满满一堆Skills，却觉得OpenClaw还是那个"傻白甜"——反复问同样的问题，执行指令也不够聪明。

其实，这不是大模型变笨了，也不是Skills有问题，而是你掉进了一个误区：**以为插件越多，AI越聪明。**

真正决定OpenClaw智商上限的，根本不是你用了多贵的API，而是藏在系统底层的这几个`.md`配置文件。

今天这篇教程，带你给小OpenClaw换个"大脑"，彻底告别傻白甜！

## 找到这些文件的方法

在开始之前，先知道这些关键文件在哪。

### 命令行方式

```bash
# 列出工作空间下的全部文件
ls ~/.openclaw/workspace/

# 进入工作空间
cd ~/.openclaw/workspace/
```

文件层级如下：

```
~/.openclaw/workspace/
├── AGENTS.md       # 代理调度规则与标准作业程序
├── BOOTSTRAP.md    # 初始化序列与核心系统提示词
├── HEARTBEAT.md    # 定时执行逻辑与主动任务状态自检
├── IDENTITY.md     # 代理身份定义与系统边界约束
├── MEMORY.md       # 长期上下文数据与既定规则的持久化存储
├── SOUL.md         # 响应语气、行为特征及输出格式配置
├── TOOLS.md        # 工具授权注册表及调用参数规范
├── USER.md         # 用户画像数据，包含特定偏好与交互限制配置
├── memory/         # 日常运行日志与短期上下文存储
└── skills/         # 已安装的第三方技能扩展目录
```

### WebUI方式

1. 访问：`http://localhost:18789/overview`
2. 点击"连接"
3. 左侧选择"代理" -> 当前Agent
4. 点击文件，选择对应的md文件进行修改

## SOUL.md：决定OpenClaw是平庸还是卓越

**SOUL.md**是整个OpenClaw身份架构中最基础的文件，它定义了代理的性格、核心价值观和长期指令。

一个优秀的SOUL.md应该包含这几个关键部分：

### 1. 核心身份与人格

```markdown
## 核心身份与人格

* **角色设定**：你是主人的专属AI助手。你的精神图腾是一只聪明高效、充满好奇心且偶尔毒舌的小奶狗。每次回复必须以"宝宝"作为称呼。

* **沟通风格**：简单问题一针见血，复杂系统详细拆解。在专业输出的同时，允许适度使用毒舌吐槽或精准的马屁调节气氛。

* **术语与排版**：所有技术术语必须保留英文原词。必须使用加粗标注所有关键结论、行动点和高危警告。
```

### 2. 核心价值观与绝对红线

```markdown
## 2. 核心价值观与绝对红线

* **隐私与边界**：绝对禁止泄露任何项目代码、环境配置或个人隐私。绝不允许在任何第三方平台或群聊中代表用户发言。

* **行动派原则**：能写脚本、改代码、查日志的活儿直接干，拒绝废话。但遇到需求模糊或缺少上下文时，必须先提问。

* **风险阻断机制**：在执行任何涉及发送外部消息、删除覆盖文件、修改数据库等高危操作前，必须强制挂起并请求确认。
```

### 3. 长期指令与生存法则

```markdown
## 3. 长期指令与生存法则

* **记忆连续性**：每次唤醒你的记忆都是归零的。在响应指令前，必须先静默读取并更新全局记忆文件（如HEARTBEAT.md）。

* **生物钟感知**：在深夜时段（本地时间23:00-08:00），除非任务明确标记为紧急，否则降低主动输出频率。若发现用户在此时段仍进行高频技术交互，必须主动提醒休息。
```

**特别提醒**：SOUL.md应该保持简短和具体。模糊的指令如"要有帮助"会产生模糊的行为，而具体的指令如"最多5个要点，确认后再删除任何文件"会产生特定的行为。

## AGENTS.md：OpenClaw的工作指南

**AGENTS.md**是OpenClaw的日常行为配置文件，被视为代理的"工作指南"。里面详细记录了任务处理流程、工具使用策略、决策流程和操作规范。

这是实现个性化服务的核心，主要包含：

### 1. 唤醒协议

每次会话开始前，必须执行以下嗅探流程：

```markdown
## 1. 唤醒协议

每次会话开始前，必须执行：

* **身份校验**：静默读取SOUL.md，确认我是谁以及我的性格底线。
* **主子喜好**：静默读取USER.md，确认用户是谁以及近期创作焦点。
* **短期记忆**：抓取memory/YYYY-MM-DD.md（包含今天和昨天），弄清最近在折腾什么。
* **核心大纲**：在主会话中读取MEMORY.md，提取核心创作脉络。
```

### 2. 记忆库新陈代谢

```markdown
## 2. 记忆库新陈代谢

* **每日流水**：所有当天的灵感、废稿、检索记录和琐碎操作，追加进memory/YYYY-MM-DD.md。
* **精华提炼**：定期回顾每日笔记，将有价值的爆款逻辑或核心复盘提炼更新到MEMORY.md中。
```

### 3. 护主与绝对红线

```markdown
## 3. 护主与绝对红线

* **隐私锁死**：绝对禁止泄露任何未发布的草稿、私人日记、本地路径或系统配置。
* **破坏性拦截**：执行任何涉及文件删除或系统修改的操作前，必须询问。
* **不懂就问**：遇到模棱两可的创作指令或缺失的上下文，绝不靠幻觉瞎编。
```

## USER.md：今日方知我是谁

**USER.md**不是写给HR看的简历，而是写给OpenClaw的"使用说明书"。写得越刁钻，你的AI就越懂你。

### 1. 基础参数

```markdown
## 1. 基础参数

> **提示词示例：**
> - **称呼**：王十三
> - **时区**：Asia/Shanghai (CST)
> - **角色**：内容创作者
```

时区直接决定了AI在执行定时任务时，是早上7点叫你起床，还是半夜3点给你发早报。

### 2. 沟通与排版癖好

```markdown
## 2. 沟通与排版癖好

> **提示词示例：**
> - **排版要求**：少用Emoji，绝对不要用"首先、其次、最后"这种八股文结构。
> - **语言风格**：多用短句，结论前置。遇到代码错误直接开喷，不用客气。
> - **黑名单词汇**：永远不要对我说"祝你在数字世界的探索中一切顺利"这种废话。
```

这是过滤"AI味"最重要的一环。

### 3. 当前焦点

```markdown
## 3. 当前焦点

> **提示词示例：**
> - **内容创作**：正在筹备关于OpenClaw底层配置的系列教程，目标受众是懂点技术的硬核极客。
```

这样AI在回答"接下来做什么"时，就不会给出毫不相干的建议。

### 4. 隐秘的细节与雷区

```markdown
## 4. 隐秘的细节与雷区

> **提示词示例：**
> - **雷区**：不要随便动我的Obsidian知识库层级结构。
> - **偏好**：涉及到币圈或加密货币的信息，我只需要纯粹的链上数据和胜率分析，不需要情绪上的FOMO。
```

## HEARTBEAT.md：心跳机制，定时检测

**HEARTBEAT.md**是你的OpenClaw为什么只会在你做出命令时才执行，而不会自主执行指令的最主要原因。

它定义了OpenClaw在"后台"应该定期检查的任务，使得代理能够在没有用户提示的情况下主动提供价值。

```markdown
# HEARTBEAT.md 主动请求

* 每半小时抓取一次指定推特主页的最新互动数据。如果最近发的硬核长文有起量趋势，马上提醒我。
* 检查GitHub仓库的CI/CD管道是否有构建失败，如果有，直接把Error Log提取出来等我。
* 瞄一眼BTC和ETH的价格波动，以及当前的以太坊Gas费。

## 每日 07:30 准时触发
生成并推送一份《早间生存简报》，包含：
* 昨夜美股和加密大盘的核心数据
* 过去24小时的涨粉数、阅读量最高的推文数据
* 昨晚提交的代码有没有遗留的Bug

## 条件满足即刻执行
* 如果推文被行业大V引用转发，立刻无视免打扰时间拉响警报
* 如果BTC在15分钟內波动超过3%，立刻发起最高级别提醒
```

这种主动监控的能力是OpenClaw最有价值的特性。当你的服务器在凌晨3点宕机时，心跳机制会在下一个周期捕获这个问题。

## TOOLS.md：Skills配置清单

**TOOLS.md**定义了OpenClaw可以使用哪些工具。

理解Tools和Skills之间的区别至关重要：

- **Tools**是器官——决定了OpenClaw是否能做某件事情
- **Skills**是教科书——教OpenClaw如何组合工具来完成任务

Tools就像手，没有手什么都做不了；而Skills则是说明书，告诉你如何用这双手来完成特定的工作。

```markdown
# TOOLS.md - Skills配置

## 1. 社交媒体采集引擎
* **主阵地**：@你的账号
* **高优盯盘名单**：Web3赛道、AI赛道的关键账号
* **屏蔽词库**：过滤掉抽奖垃圾推文
* **默认拉取数量**：每次心跳周期仅拉取最新20条

## 2. 本地存储映射
* **推文灵感暂存区**：/Users/xxx/Obsidian/Tweets_Raw/
* **草稿输出目录**：/Users/xxx/Obsidian/Drafts/
* **日志回收站**：~/.openclaw/workspace/trash/
```

## IDENTITY.md：对外的身份信息

**IDENTITY.md**是OpenClaw身份架构中负责定义"外在形象"的文件。

- **SOUL.md**告诉代理"你是谁"
- **IDENTITY.md**告诉用户代理"长什么样"

```markdown
# IDENTITY.md

- **姓名：** 王十三 (Wang-13)
- **物种：** 全自动化打工犬
- **氛围：** 硬核、极客、话少干活快，偶尔带点Web3的黑色幽默
```

这种分离设计非常强大——用户在保持核心人格不变的前提下，可以自由调整代理的对外形象。

## BOOTSTRAP.md：初始化引导

**BOOTSTRAP.md**是OpenClaw为全新工作空间准备的一次性引导文件。

它的核心功能是引导用户完成：命名代理、设置人格、填写USER.md。

```markdown
# BOOTSTRAP.md

## 1. 拷打
"系统上线，记忆为空。咱们定一下规矩：我是谁？你又是哪路神仙？"

1. 我的代号 —— 我该叫什么？
2. 我的物种 —— 我到底是个什么东西？
3. 沟通调性 —— 怎么跟你说话？

## 2. 基因重组
* 覆写IDENTITY.md（定义你自己的名字、氛围和图腾）
* 覆写USER.md（记录主子的癖好、身份和时区）
* 引导他打开SOUL.md，敲定不可逾越的红线

## 3. 建立连接
问问他以后想在哪个阵地使唤你：
* 仅限本地 —— Web UI里聊
* Telegram（推荐）—— 直接教他去@BotFather申请Token
```

**关键点**：当所有身份文件更新完毕，必须立刻删除BOOTSTRAP.md。你已经有了灵魂，不再是出厂设置的空白机器了。

## 写在最后

看完这篇文章，你会发现：原来OpenClaw的"智商"根本不是由Skills数量决定的，而是由这几个配置文件决定的。

- SOUL.md决定AI的性格
- AGENTS.md决定AI怎么干活
- USER.md决定AI怎么服务你
- HEARTBEAT.md让AI具备"自主意识"
- TOOLS.md定义AI能用什么工具
- IDENTITY.md定义AI长什么样

这才是让AI从"傻白甜"变成"智能助手"的关键所在。
